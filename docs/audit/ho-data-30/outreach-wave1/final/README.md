## Before sending
- Send from the address you want replies at. Each message asks for answers from a company address or a public link.
- Web forms may limit length. If a form truncates, send the first part and offer the rest by email.
- Keep the sent text and date. Each reply is recorded as an **owner-received manufacturer statement**: sender, date and
  edition, archived with the evidence.

## When replies arrive
Forward or paste each reply into a session. A value is accepted only if:
- it names the product and edition;
- it comes from the manufacturer's domain (or links a public document there);
- it fits the field definition stated in the message.

Accepted values go into a normal Fast Lane batch: one exact approval, then rehearsal, guarded import and verification.

A reply can also reopen a CLOSED-UNKNOWN cell from `../../closeout_register.csv`. Examples: a fingertip arm span, a
standard-hand DoF, a Wh figure. Ranges, peak or combined figures, and answers that are ambiguous between editions are
recorded as held, not as values.
